# Quick Commerce Analytics Dashboard

## Project Overview

This project analyzes 1 million quick-commerce orders from leading platforms such as Blinkit, Zepto, Swiggy Instamart, Dunzo, Big Basket, Amazon Now, Flipkart Minutes, and Jio Mart.

The objective is to uncover customer behavior, revenue trends, operational performance, and delivery insights using Python, SQL, and Power BI.


## Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* SQL
* Power BI
* DAX

## Project Workflow

### 1. Data Cleaning & Preparation

* Handled missing values and duplicates
* Standardized column formats
* Performed data validation checks

### 2. Feature Engineering

Created:

* Age Group
* Customer Rating Category
* Delivery Speed Category
* Discount Status
* High Value Orders
* Distance Category

### 3. Exploratory Data Analysis

Analyzed:

* Revenue Trends
* Customer Ratings
* Product Categories
* Delivery Performance
* Discount Impact
* Company-wise Performance

### 4. Dashboard Development

Built a 2-page interactive Power BI dashboard:

#### Business Overview

* Revenue
* Orders
* Average Order Value (AOV)
* Customer Ratings
* Revenue by Company
* Revenue by City
* Product Category Analysis

#### Operational Insights

* Delivery Time Analysis
* Average Distance per Order
* Discount Impact
* Delivery Partner Performance
* High Value Order Analysis

---

## Key Business Insights

* Swiggy Instamart generated the highest revenue among all companies.
* Gurgaon and Noida emerged as top-performing cities.
* Discounted orders recorded higher Average Order Value than non-discounted orders.
* Most deliveries were completed within the expected quick-commerce delivery window.
* Customer satisfaction remained relatively stable across delivery speed categories.
* High-value orders contributed significantly to overall revenue.
